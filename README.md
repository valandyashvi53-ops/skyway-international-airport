# skyway-international-airport
A professional airport website UI featuring flight enquiry, arrivals and departures, terminal guide, airport services, baggage information, passenger enquiry form, travel instructions, and airport help desk.
# ✈️ SkyWay International Airport

**Ahmedabad International Airport**

SkyWay International Airport is a professional airport website UI designed to provide passengers with useful flight, terminal, baggage, and airport service information in a simple and organized layout.

## ✨ Features

* ✈️ Airport Information
* 🔎 Flight Enquiry
* 🛫 Departures
* 🛬 Arrivals
* 🗺️ Terminal Guide
* 🧳 Airport Services
* 🛅 Baggage Information
* 🎫 Passenger Enquiry Form
* 📢 Important Travel Instructions
* 📞 Airport Help Desk

## 🔎 Flight Enquiry

Passengers can search for flight information using:

* Flight Number
* Travel Date

The website displays flight status information for departures and arrivals.

## 🛫 Departures

The departures section provides:

* Flight Number
* Destination
* Departure Time
* Gate
* Flight Status

## 🛬 Arrivals

The arrivals section provides:

* Flight Number
* Origin
* Arrival Time
* Baggage Belt
* Flight Status

## 🗺️ Terminal Guide

The terminal guide provides information about:

* Terminal 1 – Domestic Flights
* Terminal 2 – International Flights
* Arrival Hall
* Departure Hall

It also displays services available in each airport area.

## 🧳 Airport Services

The website includes information about:

* 🛅 Baggage Services
* 🅿️ Parking
* 🍴 Food Court
* 🛒 Shopping

## 🧳 Baggage Information

Passengers can view general baggage information for:

* Cabin Baggage
* Check-in Baggage
* Extra Baggage

## 🎫 Passenger Enquiry Form

The passenger enquiry form includes:

* Full Name
* Mobile Number
* Email
* Journey Type
* From
* To
* Travel Date
* Number of Passengers
* Wheelchair Assistance
* Special Meal
* Extra Baggage
* Passenger Message

## 📢 Important Travel Instructions

Passengers are provided with useful travel instructions, including:

1. Arrive at the airport at least 2 hours before domestic flights.
2. Keep your boarding pass and ID ready.
3. Check baggage weight before check-in.
4. Do not carry prohibited items.
5. Check the flight status before departure.
6. Follow airport security instructions.

## 🛠️ Technologies Used
